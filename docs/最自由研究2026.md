# 最自由研究2026：企画前提

最終確認日：2026年7月26日

この文書は、制作中に企画の前提を見失わないための記録です。提出直前には必ず公式サイトを再確認してください。

## 企画の位置づけ

- 2021年に始まった視聴者参加型の自由研究発表会。
- 2026年は6回目。
- ゲームの追求、ものづくり、文章・日記、検証など、面白そうなことであればテーマは幅広く認められる。
- 学術論文の形式に限定されず、提出された動画・資料・文章等をカシヲ氏が配信で紹介する形式。
- 公式ページには賞や順位の記載はなく、競争より発表・鑑賞を中心とする企画として扱う。

## 2026年日程

- 応募期間：2026年9月1日〜5日
- 発表会：2026年9月19日から
- 終了日、各日の配信時間、提出フォームURLは7月26日時点で未掲載。

## 提出数と時間

- 1人につき原則最大2点。
- 泥団子部門のみ別枠で1点追加でき、最大3点。
- 1点につき20分以内厳守。
- 1つの研究を前後編として2枠に分けることはできない。
- 無関係な複数研究を1枠にまとめることは非推奨。まとめる場合は、研究同士に関連性を持たせ、1つの研究として成立させる。

このリポジトリでは複数の候補研究を管理できるが、提出時には上記の枠数へ絞り込む。

## 形式

- 提出形式は動画、文章、画像など自由。
- 動画：YouTube限定公開推奨、またはMP4。
- 文章：Googleスライド推奨、PDF、ブログ、フォームへの直接入力など。
- 画像：JPG、PNGなど一般的な形式。
- PowerPointはカシヲ氏側の環境でフォント崩れが起きる可能性がある。
- その他も一般的なPCで開ける形式なら提出可能。
- URLで提出するものは、第三者が閲覧できる公開状態にする。

Webスライドは「一般的なPCで開けるURL」として制作する。提出フォームがWeb URLをどの項目で受け付けるかは、フォーム公開後に確認する。

## 内容・権利

次を含むものは配信で発表できない。

- 公序良俗に反する表現（差別的、攻撃的、過激な内容など）
- Twitch、YouTube等の配信プラットフォーム規約に違反する内容
- 著作権を侵害する内容

制作時の注意：

- 音源は権利を侵害しないフリー素材等を使う。
- 著作物の画像や資料には引用元・出典を明記する。
- ゲーム映像はゲーム会社の配信ガイドラインに従う。
- 外部音声合成を使う場合は、ソフト、話者、キャラクターの最新規約を個別に確認する。

## 提出・保管

- 提出物は発表当日まで自分でも保管する。
- 不具合時に再送できるよう元データを残す。
- アップローダーを使う場合、ダウンロード期限を可能なら発表会まで設定する。
- カシヲ氏に何かをしてもらう研究で、応募期間内では準備できない可能性がある場合、事前にXのDMまたはメールで相談する。内容によって協力できない場合がある。

## 泥団子部門

- 泥団子作成キットを使わない。
- 子どもの頃の記憶を頼りに作る。
- 条件違反の泥団子も通常研究枠なら提出できるが、泥団子部門の追加枠にはならない。
