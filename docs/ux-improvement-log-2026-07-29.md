# UX改善ログ 2026-07-29

## 対象となる利用者の流れ

1. Twitchでログインする。
2. AIクライアントとの対話から研究を作る。
3. Web UIで研究内容と画像を確認・微調整する。
4. 一枚編集画面でスライド、見た目、読み上げを調整する。
5. 必要ならVOICEVOX音声を生成する。
6. 固定プレビューを確認して公開する。

## 初回監査で見つかった課題

| 優先度 | 課題 | 影響 |
|---|---|---|
| 最優先 | 同じ画面にある複数フォームのversionが相互に同期されない場合がある | 連続編集の2回目が競合し、初心者には原因が分からない |
| 最優先 | 発表設定の変更後にプレビューが古いことを必ずしも表示しない | 変更前の版を誤って公開し得る |
| 高 | VOICEVOX設定後の未生成区間がプレビューを塞ぐ | ブラウザ音声フォールバックがあるのに制作を進められない |
| 高 | プロジェクト詳細に機能が並ぶだけで、次の操作が分からない | 研究から公開までの現在地を利用者自身が推測する必要がある |
| 高 | 未保存のまま別画面へ移動できる | 入力内容を失う |
| 中 | AIでしかできない操作の依頼文を利用者が考える必要がある | AI Agentを初めて使う人ほど開始しづらい |

## 改善ループ1

- ページ内の全編集フォームでproject versionを同期する共通処理へ統合した。
- どの編集フォームを保存しても、既存プレビューを要再生成として扱うようにした。
- 未保存フォームがある状態でページを離れる場合にブラウザ警告を出すようにした。
- VOICEVOX未生成区間があっても、ブラウザ音声で固定プレビューを作成できるようにした。
- 研究内容、発表構成、プレビュー、公開の4段階と次の操作を示す進行パネルを追加した。
- AIへ依頼する文章をコピーできる導線を、研究が空の場合とスライド未作成の場合に追加した。
