# 最自由研究 制作・発表ワークスペース 利用者ガイド

最終更新: 2026-08-01

公開中の利用者向け案内は [`/guide`](https://saijiyu-kenkyu.2764.moe/guide) を正本とする。この文書は、運営・開発時に説明の境界と初回体験を確認するための補助資料である。

## 正式な説明

最自由研究 制作・発表ワークスペースは、最自由研究の発見・記録・発表制作を、Remote MCP対応AIとの対話とブラウザの実画面で一続きに進める、限定利用者向けサービスである。

- AIでは、テーマ発見、問い・仮説・方法・結果の整理、発表構成、小単位の編集を行う。整理した内容はスライド本文と読み上げ原稿として保存する。
- Web UIでは、Twitch本人確認、研究一覧、画像、実表示、文言とデザインの微調整、VOICEVOX、品質確認、固定プレビュー、公開を扱う。
- 研究データはversion付きで保存し、利用者ごとに分離する。
- AIによる編集は下書きを変更する。一般公開は、本人が固定プレビューを確認して明示的に公開した場合だけ行う。
- 任意HTMLやshellを実行する汎用ホスティングではない。検証済みschemaとrendererの範囲で表現する。
- AIサービス自体の契約や利用枠は、このサービスに含まれない。

## 初回体験の完了条件

1. `/guide` で必要条件とAI・Web UIの役割を理解する。
2. Web UIへTwitchログインし、利用資格を確認する。
3. Claude、Codex、ChatGPTのうち、任意のRemote MCPを登録できる環境へ `https://saijiyu-kenkyu.2764.moe/mcp` を登録する。
4. AIクライアント側でも同じTwitchアカウントによるOAuthを完了する。
5. AIに最初の依頼文を送り、研究を一件作成する。
6. Web UIの「自分の研究」に作成した研究が表示されることを確認する。

最初の依頼文:

```text
最自由研究MCPを使って、新しい研究を対話しながら作りたいです。まず興味のあることを一つずつ聞いてください。
```

## どのAIを選ぶか

料金より先に、現在の画面へ任意のRemote MCP URLを登録できるか確認する。

1. Claudeに「Add custom connector」がある場合は、そのままClaudeを使える。Freeはカスタムコネクタ1件までなので、インストールなしで試す第一候補とする。
2. Codexに「MCP servers」がある、または`codex mcp`を使える場合は、そのままCodexを使える。長時間の制作、検証、細かな反復を自律実行したい場合の第一候補とする。
3. ChatGPTの「Settings」→「Security and login」に「Developer mode」がある場合は、Pluginsから登録できる。利用可否はアカウントとworkspace policyに依存するため、プラン名だけで可否を判断しない。
4. どれもない場合、インストールなしならClaude Free、インストール可能で制作・検証を重視するならCodex、対話と文章を重視するならClaudeを選ぶ。

2026-08-01時点の個人向け料金表示は次の通り。米ドル表示であり、地域、税、年払い、提供状況により変わる。

| 環境 | 最小の始め方 | 継続利用の目安 |
|---|---|---|
| Claude | Free $0。カスタムRemote MCPは1件まで | Pro $20/月。Claude Codeを含む。Maxは$100/$200 |
| Codex | Free $0、Go $8/月。利用中のCodex clientにMCP設定があることを確認 | Plus $20/月。Proは$100/月から |
| ChatGPT | 現在の契約でDeveloper modeの表示を先に確認 | MCPだけを目的にしたプラン変更は、表示可否を確認するまで勧めない |

迷った場合は、初回確認をClaude Freeで行い、継続的な制作ではCodex PlusまたはClaude Proを比較する。普段のChatGPTを使い続けたい場合はDeveloper modeが実際に表示されるときだけChatGPT経路を選ぶ。

## Codex

推奨するCLI手順:

```bash
codex mcp add saijiyu-kenkyu --url https://saijiyu-kenkyu.2764.moe/mcp
codex mcp login saijiyu-kenkyu
codex mcp list
```

Codexセッション内では `/mcp` で接続状態を確認する。GUIから設定する場合は「MCP servers」でStreamable HTTPサーバーとして同じURLを追加し、「Authenticate」から認証する。

設定ファイルを直接編集する場合:

```toml
[mcp_servers.saijiyu-kenkyu]
url = "https://saijiyu-kenkyu.2764.moe/mcp"
```

その後 `codex mcp login saijiyu-kenkyu` を実行する。

## Claude Code

個人の複数の作業フォルダから使えるよう、user scopeを推奨する。

```bash
claude mcp add --transport http --scope user saijiyu-kenkyu https://saijiyu-kenkyu.2764.moe/mcp
claude mcp get saijiyu-kenkyu
claude mcp list
```

Claude Codeを開き、`/mcp` から `saijiyu-kenkyu` を選んでOAuthを開始する。ブラウザが自動で開かない場合は、表示された認証URLを手動で開く。認証後のcallbackでブラウザエラーが出た場合、アドレスバーの完全なcallback URLをClaude Codeの入力欄へ貼り付ける復旧方法がある。

## Claude Web／Desktop

個人利用では次の順に追加する。

1. 「Customize」→「Connectors」→「＋」→「Add custom connector」を開く。
2. 名前を「最自由研究」、Remote MCP server URLを `https://saijiyu-kenkyu.2764.moe/mcp` にする。
3. Client IDとClient Secretは指定せず追加する。
4. 「Connect」からTwitch認証を完了する。
5. 会話ごとに入力欄の「＋」→「Connectors」から有効にする。

Team／Enterpriseでは、OwnerがOrganization settingsでコネクタを追加した後、メンバーが自分のTwitchアカウントで接続する。

## ChatGPT

1. 「Settings」→「Security and login」を開き、「Developer mode」が表示されるか確認して有効にする。
2. [ChatGPT Plugins](https://chatgpt.com/plugins)を開き、「＋」から名前、説明、Remote MCP URLを登録する。
3. 新しい会話の「＋」→「More」から登録した最自由研究を有効にする。
4. 求められた場合は、Web UIと同じTwitchアカウントで接続を許可する。

Developer modeの提供はアカウントとworkspace policyに依存する。表示されない場合は、先に課金せずCodexまたはClaude Freeを使う。

## OAuthで誤解しやすい点

- Web UIのログインとAIクライアントの接続許可は別セッションである。初回は両方でTwitch認証を行う。
- TwitchのパスワードやtokenをAIの会話へ貼らない。
- 認証後に `http://127.0.0.1` または `http://localhost` が開くのは、CLIが端末内で待ち受けるOAuth callbackとして正常である。
- 認証画面が期限切れの場合は古いタブを閉じ、新しい認証を一度だけ開始する。ボタンを連打しない。
- Web UIとAI側で異なるTwitchアカウントへログインすると、同じ研究は見えない。

## 説明品質の基準

利用者向け案内は次を満たす。

- 「何ができるか」だけでなく、AIとWeb UIの役割、できないこと、公開境界を先に説明する。
- Claude、Codex、ChatGPTの判断フローをRemote MCP登録可否から始め、料金はその後に示す。
- Codex、Claude Code、Claude Web／Desktop、ChatGPTを別の手順として示す。
- コマンド、設定値、認証操作、接続確認、最初の依頼までを省略しない。
- `127.0.0.1`、期限切れ、ブラウザが戻らない、toolが見えない、再認証の復旧方法を示す。
- password、token、Client Secretを利用者に貼り付けさせない。
- 現在の実装にない自動公開、一般的な任意コード実行、AI契約の提供を約束しない。
- 外部クライアントの画面名やコマンドは公式資料を再確認して更新する。
