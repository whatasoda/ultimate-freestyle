# 研究固有デザイン UX改善ログ（2026-07-31）

テンプレートを選んで終わる体験から、作者の好みと研究テーマを反映した一貫性ある発表を作る体験へ移すため、3時間相当の観点別ループとしてモデル、編集、表現、AI連携、狭幅、品質、配信を確認する。

## 改善ループ168：既存自由度の棚卸し

- 既存templateには色、font、領域、余白、密度、動きがあり、canvasとsceneでは一枚ごとの自由構成もできることを確認した。
- visual presetが配色と装飾を同時に決めるため、利用者からは完成済みtemplateを選ぶ体験に見えやすいことを主要課題とした。

## 改善ループ169：デザイン意図の正本

- templateへ`design_notes`を追加し、研究テーマ、作者の好み、避けたい表現を1,000文字以内で保存できるようにした。
- 発表画面へ表示する文ではなく、Web UIとAI Agentが後続の個別設定を同じ意図へ揃えるための情報とした。

## 改善ループ170：プリセットから装飾軸を分離

- 背景モチーフ6種、見出し処理5種、画像処理4種をvisual presetと独立したtokenとして追加した。
- モチーフは色、濃さ、大きさも個別に変えられ、同じpaperやscientificを起点にしても研究ごとに異なる画面を作れるようにした。

## 改善ループ171：保存前の実表示

- Web UIの変更を同一rendererへ即時送信し、保存前に現在スライドで組み合わせを確認できるようにした。
- 選択肢を文字だけのselectにせず、モチーフ、見出し、画像処理の小さな見本を併記した。

## 改善ループ172：AI Agentの小粒度編集

- 既存の`update_presentation_template_fields`へ新しい項目を追加し、大型schemaや任意CSS toolを増やさず一項目ずつ変更できる形を保った。
- 発表デザインガイドとdeck resourceへデザイン方針・装飾設定を載せ、接続したAIが作者の意図を読み返せるようにした。

## 改善ループ173：rendererの安全な表現

- モチーフは専用の装飾layerへ描画し、本文、補足、canvas、scene、読み上げのデータと分離した。
- 見出しと画像は検証済みdata attributeとCSSだけで処理し、任意HTML、CSS、外部font、外部画像URLは受け付けない。

## 改善ループ174：画面幅と可読性

- 2,048×1,041と390×844で波モチーフ、アクセント線、scientific、独自配色を組み合わせた実rendererを確認した。
- 両方で横溢れ、操作ボタンの見切れ、stage比率崩れがなく、モチーフが本文より背面に留まることを確認した。

## 改善ループ175：契約・配信

- schema、renderer、Web UI、MCP resource、部分更新toolへ契約テストを追加し、rendererとdashboard assetの版を更新する。
- 全体テスト、Cloudflare dry-run、main push、自動デプロイ、本番healthとasset配信を確認する。
