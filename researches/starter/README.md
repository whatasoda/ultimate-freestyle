## 研究メモ

- 仮タイトル：
- 研究の問い：
- 予想・仮説：
- 方法：
- 必要な素材：
- 結果：
- 考察：
- 発表で一番見せたいもの：

## 制作チェック

- [ ] 研究が1つの発表内で完結している
- [ ] 発表時間が20分以内
- [ ] 引用元・素材元を記録した
- [ ] ゲーム映像等の配信ガイドラインを確認した
- [ ] 外部URLが第三者から閲覧できる
- [ ] 元データと提出データを手元に保管した
- [ ] 本番と同じ端末・ブラウザで通し練習した
- [ ] 画面の表示文と実際の読み上げ内容が一致している
- [ ] 原稿表示を `dialogue`・`commentary`・`inline` から選んだ

## 素材

画像や音声は `public/researches/starter/` に置き、
`/researches/starter/ファイル名` として参照します。

開発中の読み上げはブラウザ音声を標準とします。ローカルVOICEVOXの確認用MP3は
`public/.voicevox-preview/researches/starter/audio/` に生成され、Gitには含まれません。

本番用VOICEVOX MP3もGitHub Actionsだけで生成し、Pages成果物へ組み込みます。
`public/researches/starter/audio/` へ生成MP3を手動追加・コミットしません。
